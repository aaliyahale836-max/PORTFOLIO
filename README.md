
# Aaliyah's Personal Website

## About
This is my personal website created to introduce myself,
my interests, hobbies and activities.



## Technologies Used
- HTML5
- CSS3
- Git
- GitHub

## Directory Structure

personal-website/
- index.html
- style.css
- images/
- README.md
- screenshots/

## How to View the Website

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Responsive Design

CSS media queries were used to make the website
adapt to desktop, tablet and mobile screen sizes.

## Reflection

During this assignment, I improved my personal
website using HTML and CSS. I learned how to use
semantic HTML elements to organise my content and
CSS media queries to make my website responsive.

One challenge I experienced was ensuring that
the website displayed correctly on different
screen sizes. I also learned how to organise
files and use local and externally hosted images.

Working with GitHub helped me understand how
branches, commits and Pull Requests are used
to manage changes in a project. I learned the
importance of saving work regularly and using
meaningful commit messages.

Overall, this assignment helped me improve
my web development skills and understand
how to manage a website project professionally.
